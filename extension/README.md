# 取数插件：taobao-cli 取数桥

让本工具通过你**日常 Chrome 里已经登录的生意参谋**读取数据。Windows 必须装；Mac 可选，不装就直接读 Chrome 里的登录。

这个插件是共用的：生意参谋、万相台、千牛、达摩盘、1688、竞品评价等店铺数据工具都用它，装一个就够。

## 先看装没装

运行 `scripts/sycm.sh doctor`（Windows：`scripts\sycm.cmd doctor`）。别的工具装过、版本够新，它会直接连上，看到 `probe = ok` 就不用再装。提示没装、太旧或文件夹不见了，再照下面做。

## 安装（约 2 分钟，只需一次）

先把 zip 解压，找到 `sycm-cli\extension\unpacked` 这个文件夹（里面有 `manifest.json`）。

1. Chrome 地址栏输入 `chrome://extensions`，回车。
2. 打开页面**右上角**的「开发者模式」开关。页面**左上角**会出现三个按钮。
3. **先清掉旧插件**：如果有「dmp-cli 达摩盘取数桥」「taobao-voc 取数桥」或旧版「taobao-cli 取数桥」卡片，逐个点「移除」。
4. 点**最左边**的「**加载已解压的扩展程序**」。⚠️ 不要点中间的「打包扩展程序」，那是给开发者用的，装不上。
5. 在弹出的选文件夹窗口里一层层点进 `sycm-cli` → `extension`，**点中 `unpacked`**，点「选择文件夹」。
6. 页面上出现「**taobao-cli 取数桥**」卡片。核对两件事：**ID 是 `gifdenhgccikkfbodclkdbohicghfhco`**，右下角开关是**蓝色（打开）**。
7. 在**同一个 Chrome** 里登录 https://sycm.taobao.com。
8. 再运行一次 `scripts/sycm.sh doctor`，看到 `probe = ok` 就装好了。

插件是从哪个文件夹加载的，就别删、别移动那个文件夹，不然插件会失效。

Windows 每次开 Chrome 可能弹「停用开发者模式的扩展程序」，点**关闭**，不要点「停用」。

## 装错了 / 连不上

| 现象 | 原因和做法 |
|---|---|
| 提示「插件的 ID 不对」，或一直连不上而卡片 ID 不对 | 装的不是 `unpacked`。把所有取数桥卡片点「移除」，从第 4 步重来 |
| 点了「打包扩展程序」，弹出「私有密钥已存在」「必须存在输入目录」 | 点「取消」，回到第 4 步点最左边那个按钮 |
| 卡片开关是灰色 | 点一下打开 |
| 提示插件「太旧」或「文件夹不见了」 | 在 `chrome://extensions` 移除旧的取数桥，再加载本工具自带的 `extension/unpacked` |
| 一直等到超时，但 ID 正确、开关打开 | ① Chrome 必须开着；② 插件每 30 秒醒一次，命令会等 40～60 秒，再试一次；③ 点插件图标，看「生意参谋」有没有被勾掉；④ 命令是在 AI 助手里跑的，换成你自己打开的终端跑一次，助手的沙箱可能拦了本机端口 |
| 提示「这个浏览器里还没有登录这个平台」 | 在这个 Chrome 里打开 https://sycm.taobao.com 登录一次 |

## 安全边界

| | |
|---|---|
| 做什么 | 只在你已登录的后台页面里替本机命令发只读请求，结果只交给本机正在运行的命令 |
| 不做什么 | 不修改任何内容；不读登录凭据（cookie2 等）；不发往任何服务器、不存储、不上传 |
| 谁能指挥它 | 只有本机命令行，且必须带插件自己的身份头；网页脚本伪造不了 |
| 每个后台能做什么 | 插件里逐个后台登记了允许的接口，名字像写操作的一律拒绝 |
