# 字段字典 + 万能查询 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 sycm-cli 与 alimama-cli 各加一份机器可读字段字典 + 万能查询参数,让 AI 主力走"查字典→自由选列取数",预设命令降级为快捷方式。

**Architecture:** 每仓库一个静态 `fields.json`(词条=字段码/中文名/scope/格式/verified状态/口径备注);CLI 启动时加载,`--fields`/`--all-fields` 参数把任意字段码透传给接口;所有请求仍走 CLI 既有安全管道(限速/夜禁/风控熔断/只读)。

**Tech Stack:** Python 标准库 + 现有依赖(browser-cookie3, curl-cffi/requests),无新依赖。

## Global Constraints

- 字典文件永远不含真实数值/店名,只有字段码/中文名/口径(可进公共库)
- 只读:不新增任何写接口调用
- SKILL.md 与 README.md 分开:README 只一句话指引,不复制 SKILL 内容
- 测试全部 mock,不打真实接口;实测验收单独做(只读)
- 示例/测试里的数字一律用假占位值
- 公共库推送前必须用户确认

```python
FIELDS_PATH = Path(__file__).resolve().parent / "fields.json"

def load_fields_dict() -> dict[str, dict]:
    """字段字典;缺失/损坏不崩,退回空字典并提醒。"""
    try:
        return json.loads(FIELDS_PATH.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as e:
        print(f"⚠️ fields.json 不可用({e}),退回内置字段表", file=sys.stderr)
        return {}

FIELDS_DICT = load_fields_dict()
```

```python
def _chrome_cookie_file() -> str | None:
    prof = os.environ.get("SYCM_CHROME_PROFILE")
    if not prof:
        return None
    p = Path.home() / "Library/Application Support/Google/Chrome" / prof / "Cookies"
    return str(p)
```
